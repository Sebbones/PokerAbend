# Survival-Abend

Alle Regeln, DE/EN-Gestaltung, Lebensabzug, Gleichstände, Ausschluss von Ausgeschiedenen und Wiederherstellung sind im [Gesamtbericht](../party-brett/README.md) beschrieben. Eigene Leuchtturm-Szene und Lebensanzeigen unter `public/games/survival-abend/`.
